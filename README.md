# 💰 Expense Tracker

A simple and intuitive web app to help users **track and categorize their income and expenses**. Built with **HTML, CSS, and JavaScript**, integrated with **Pabbly** and **Airtable** and deployed on **Netlify**.

---

## 🧩 Features

- **Add transactions** easily with title, amount, date, and category  
- **Filter** by category, date range, or amount  
- **Visualize totals**: overall, income vs. expense, category breakdown  
- **Persistent storage** using Airtable via Pabbly automation  
- **Responsive UI** for both desktop and mobile
